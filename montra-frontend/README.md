# Finance Tracker Application

A modern, responsive financial management web application built with React, Vite, Tailwind CSS, and Axios.

## Features
- **Dashboard Overview:** Real-time financial summary & analytics.
- **Transactions Management:** Search, filter, add, and audit income/expenses.
- **Accounts:** Manage bank accounts, credit cards, and cash flow.
- **Budgets & Categories:** Set monthly limits and visual targets.
- **AI Chat Assistant:** Quick financial queries and auto-tagging suggestions.
